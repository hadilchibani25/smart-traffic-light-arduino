# 🚦 Smart Traffic Light System using Arduino

## 📌 Project Overview
This project implements a Smart Traffic Light System using Arduino Uno. It simulates traffic light sequences and uses an ultrasonic distance sensor to detect approaching vehicles and adjust the green light duration.

## 🔧 Hardware Components
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Blue LED
- Push Button
- Ultrasonic Distance Sensor
- Resistors
- Breadboard
- Jumper Wires

## ⚙️ Features
- Automatic traffic light sequencing.
- Push-button ON/OFF control.
- Vehicle detection using an ultrasonic sensor.
- Extended green light duration when a vehicle is detected within 20 cm.
- Non-blocking traffic light timing using `millis()`.
- Button debouncing for reliable button detection.

## 💻 Programming Concepts
- C/C++ programming
- Digital Input and Output
- `millis()` for time management
- Debouncing
- Conditional statements
- Ultrasonic distance measurement
